# O QUE É ISSO?

Este é o SRD de Daggerheart (System Reference Document - Documento de Referência do Sistema). É um repositório dos elementos mecânicos do sistema Daggerheart, editado e organizado para clareza, concisão e consulta rápida.

Você pode usar este SRD de várias maneiras:

- Para consultar rapidamente as regras oficiais de Daggerheart durante as sessões de jogo.
- Para garantir que qualquer conteúdo caseiro (homebrew) que você criar ou publicar esteja em conformidade com o conjunto de regras principais de Daggerheart.
- Para fornecer o texto disponibilizado pela Darrington Press para suas próprias publicações sob a licença de jogo da comunidade (Community Gaming License - www.darringtonpress.com/license).
- Para entender melhor as mecânicas de Daggerheart, sem as informações de ambientação e estilo, para que você possa adaptá-las ou modificá-las no processo de criação do seu próprio conteúdo.

O SRD de Daggerheart não substitui o livro de regras principal, que contém informações sobre o cenário, exemplos adicionais de vários elementos de jogo e muitos conselhos excelentes para jogar Daggerheart — sem mencionar a arte e o layout deslumbrantes.

Em resumo, este é o sistema Daggerheart reduzido ao essencial — uma oferta enxuta e limpa, sem todo o sabor, estilo e material de apoio que tornam o livro de regras principal uma leitura tão evocativa e agradável. Esperamos que este documento seja útil para a sua mesa. Boas aventuras!
